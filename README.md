# Nosy SMP Website

A static website built for a private Minecraft server (SMP) for friends — the front-end and server info hub players used to check details before joining.

## Overview

This project is a simple, self-contained static site: no backend, no build process, just HTML/CSS/JS served directly. It was a small early project focused on structuring a multi-page site with a consistent layout using Bootstrap. 

## Tech Stack

- HTML / CSS
- Bootstrap (for layout and components)
- Vanilla JavaScript

## Structure

├── css/ # Custom styling
├── img/ # Site assets and images
├── js/bootstrap/ # Bootstrap framework files
└── index.html # Main entry point
